## 1. О проекте

Telegram Mini App для игроков в Dota 2. Не замена Dotabuff, а «карманный справочник + социальная игра»: быстрый просмотр статистики + баттлы 1v1 между друзьями.

**Одна фраза:** быстрый доступ к статистике Dota 2 и социальные соревнования с друзьями прямо из Telegram — без переключения на браузер и тяжёлые сайты.

---

## 2. Проблема

- Чтобы посмотреть статистику друга или свою, нужно открыть браузер, зайти на Dotabuff/STRATZ, найти игрока. В переписке это долго и неудобно.
- Существующие сервисы перегружены аналитикой, рассчитаны на «вдумчивый» просмотр за компьютером.
- В Telegram нет удобного способа быстро глянуть статы и поделиться ими в чате.

## 5. Ценностное предложение

Почему будут пользоваться именно этим:

1. **Скорость:** открыл из чата — увидел статы за 2 секунды.
2. **Социальность:** баттл с другом запускается прямо в чате, счёт обновляется автоматически при открытии.
3. **Возвращаемость:** баттл — это повод открыть приложение завтра, а не один раз.
4. **Простота:** не «всё как у Dotabuff», а одна-две вещи, но хорошо.

**Позиционирование:** не конкурент Dotabuff, а «карманный справочник + социальная игра вокруг Dota», которая живёт там, где вы общаетесь.

## 6. Конкуренты

| Конкурент | Что делает | Сильные стороны | Слабые стороны / наша ниша |
|-----------|------------|-----------------|----------------------------|
| Dotabuff | Аналитика Dota 2 | Бренд, глубина данных | Не для Telegram, тяжёлый |
| STRATZ | Самые полные данные | Полнота | Академичный, не для чата |
| OpenDota | API + сайт | Открытые данные | Не UX-продукт |
| Dota 2 Pro Tracker | Статы про-игроков | Ниша | Не для обычных игроков |
| Sweet Hub | Premium-аналитика в TG | Уже в TG | Платно, фокус на аналитике |
| GGQ | Экосистема в TG | Монетизация | Сложность, широта |

**Наш вывод:** место есть за счёт простоты, социального контекста и игровых механик (баттлы), а не за счёт глубины данных. Прямых конкурентов с дуэлями на рынке TMA сейчас нет.

## 8. Функциональные требования

### 8.1 MVP

| # | Фича | Описание | Приоритет |
|---|------|----------|-----------|
| F1 | Просмотр профиля игрока | Steam ID → базовая статистика (MMR, winrate, кол-во матчей) | Must |
| F2 | Последние матчи | Список последних N матчей с базовой инфой | Must |
| F3 | Топ героев | Топ-3/5 героев по кол-ву игр или винрейту | Should |
| F4 | Поиск игрока | Ввод Steam ID или привязка | Must |
| F5 | Кнопка «Поделиться» | Отправка ссылки в чат (обычная TMA-ссылка, без генерации OG) | Should |
| F6 | Тёмная/светлая тема | Автоматически из Telegram | Must |
| F7 | Баттл (дуэль) 1v1 | Два игрока, окно 48ч, метрика «победы». On-demand обновление. Экран «кто ведёт». | Must |
| F8 | Приглашение друга | Кнопка → ссылка в чат → invite_token | Must |
| F9 | Пуш-уведомления | Старт, статус, результат | Should |

### 8.2 Правила баттла

| Параметр | Решение |
|----------|---------|
| Формат | Дуэль 1 на 1 |
| Метрика | Количество побед за окно |
| Зачётные матчи | All Pick (game_mode 1 и 22). Турбо (23), отменённые, боты — нет. |
| Окно | 48 часов (от момента принятия) |
| Стартовый запрос | Немедленный запрос к API при старте |
| Опрос | On-demand при открытии (если прошло > 10 мин) + кнопка «Обновить» (троттлинг 5 мин). Фоновый fallback — каждые 45 мин. |
| Совместные матчи | Если оба участника в одной команде — матч не засчитывается ни одному |
| Ничья | При равенстве — finished с winner_id = NULL. [Пересмотреть после валидации] |
| Реванш | После завершения — кнопка «Реванш» (новый баттл с теми же параметрами) |
| Привязка Steam | Вручную, Steam ID. OpenID — в будущем. |
| Уведомления | Пуш через бота + при открытии. Требует /start. |

### 8.3 Вне скоупа MVP

- Полная аналитика матчей
- Про-трекер
- Предсказания и ставки
- Личные челленджи

### 8.4 Вторая версия (после валидации)

- Групповые баттлы (5 на 5, турнирная сетка)
- Сравнение двух игроков на одном экране

- Кастомные профили и косметика

- Вход через Steam OpenID
- Другие метрики (крипы, KDA, GPM)

## 9. Монетизация

**Модель:** Freemium через Telegram Stars (XTR).

| Бесплатно | Платно |
|-----------|--------|
| Базовая статистика | Углублённая аналитика |
| Последние N матчей | Больше матчей / история |
| Стандартный профиль | Кастомные темы, рамки, значки |

**Гипотеза:** готовы ли люди платить Stars за косметику/данные.

**Ожидание:** на старте доход символический. Цель — проверить механику.

## 12. Roadmap

| Этап | Что делаем | Результат | Длительность |
|------|------------|-----------|-------------|
| **1. Прототип** | Один экран с фейковыми данными, вёрстка, Telegram SDK | Понимание TMA-стека | ~1 нед |
| **2. Интеграция** | Реальные данные OpenDota через прокси, Redis-кэш, HTTPS для тестов | Работающий профиль | ~1 нед |
| **3. Баттл** | Создание/принятие, подсчёт, on-demand опрос, проверка совместных матчей | Работающий баттл 1v1 | ~2–3 нед |
| **4. Социальность** | Приглашение, пуши, реванш | Продукт, которым хочется делиться | ~1 нед |
| **5. Полировка** | Ошибки, тема, MainButton, BackButton | Продукт, которым не стыдно поделиться | ~1 нед |
| **6. Валидация** | Показать 5–10 друзьям, собрать фидбек | Понимание, стоит ли продолжать | ~1 нед |
| **7. Монетизация** | Stars, политика, лицензия OpenDota | Готовая механика | ~1 нед |

**Итого до валидации:** ~8–10 недель.
